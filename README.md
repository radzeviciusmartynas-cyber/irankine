Adresas: https://radzeviciusmartynas-cyber.github.io/irankine/

Viduje: mokymų užduotys ir viktorina, laiškų konstruktorius, el. pašto parašas pagal Kolegijos standartą, šablonai, chato taisyklės ir posėdžių atmintinė.
